# داشبورد مدیریتی مکث‌سیلور

این مخزن فقط بستهٔ مستقل داشبورد را نگه می‌دارد؛ فایل‌های دیگر پروژه در آن نیستند.

- اجرای صفحه: `index.html`
- آزمون داده‌ها، مناطق، خروجی نقشه و منابع فونت: `node validate_dashboard.mjs`
- فونت Estedad، فونت جاسازی‌شدهٔ خروجی و آیکون در `assets/` قرار دارند.

## داده و محرمانگی

صفحه شامل داده‌های فروش تعبیه‌شده است؛ پیش از اشتراک‌گذاری، مجازبودن انتشار این داده‌ها را تأیید کنید. مخزن باید خصوصی بماند.

خصوصی‌بودن مخزن به‌تنهایی صفحهٔ GitHub Pages را خصوصی نمی‌کند؛ Pages معمولاً برای همهٔ دارندگان لینک عمومی است. این بسته را تا زمان فراهم‌شدن میزبانی با کنترل دسترسی واقعی منتشر نکنید. رمز مشترک باید سمت سرور بررسی شود؛ قرار دادن فرم یا رمز در HTML/JavaScript از داده‌های داخل صفحه محافظت نمی‌کند.

منابع فونت Estedad همراه مجوز SIL Open Font License در `assets/fonts/OFL.txt` ارائه شده‌اند.
