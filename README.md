# درگاه مدیریتی مکث‌سیلور

این بستهٔ استاتیک شامل سه صفحهٔ یکپارچه است:

- `index.html` — درگاه مدیریتی و مسیر ورود به داشبوردها.
- `ceo-dashboard.html` — نسخهٔ یکپارچهٔ داشبورد تعاملی CEO؛ فایل مبدأ اصلی در پوشهٔ `dashboard/` دست‌نخورده می‌ماند.
- `sales-analysis.html` — تحلیل محلی گزارش‌های مشتری، کالا یا فایل تراکنش استاندارد.

## اجرا و بررسی

برای اجرای محلی در پوشهٔ بسته:

```powershell
python -m http.server 8769
```

سپس `http://127.0.0.1:8769/` را باز کنید. Excel parser، QR generator، فونت Estedad و آیکون‌ها به‌صورت محلی در `assets/` قرار دارند؛ صفحه برای کارکرد تحلیلی به CDN وابسته نیست.

اعتبارسنجی‌ها:

```powershell
node validate_dashboard.mjs
node validate_portal.mjs
```

## منبع و معنای داده

گزارش «فروش» شامل ردیف‌های مشتری/گروه مشتری و مبلغ سالانه است؛ گزارش «کالا» شامل کد کالا، عنوان، مقدار و خالص فروش سالانه است. این دو خروجی کلید تراکنش مشترک ندارند و در سامانه با یکدیگر Join نمی‌شوند. ستون‌های استان، کانال، برند و مدل از نام آزاد یا حدس استخراج نمی‌شوند. فقط با ورود دادهٔ ریزِ دارای ستون‌های مربوط، فیلترهای آن ابعاد فعال می‌شوند. منطقه در فایل تراکنش در صورت نبود ستون منطقه، از روی استان با نگاشت شش‌گانهٔ مصوب داشبورد CEO محاسبه و به‌عنوان مقدار مشتق‌شده مشخص می‌شود.

واحد مبلغ در شش فایل سالانه صریح نیست؛ پیش‌فرض صفحه مبلغ خام را بدون برچسب ریال/تومان نشان می‌دهد. انتخاب واحد در رابط فقط یک یادداشت نمایشی است و هیچ تبدیلی انجام نمی‌دهد. ردیف‌های جمع کلِ بدون کد برای جلوگیری از شمارش دوباره حذف می‌شوند.

طرح ستون‌ها و قالب خالی تراکنش‌ها در `data/transaction-schema.json` و `data/transaction-template.csv` آمده‌اند. طرح تراکنش یک ردیف به‌ازای هر قلم فاکتور می‌خواهد تا تحلیل محصول، مشتری و استان واقعاً به هم مرتبط باشد.

## حریم خصوصی و انتشار عمومی

این نسخه برای انتشار عمومی آماده شده و داشبورد CEO شامل داده‌های فروش تجمیع‌شدهٔ استانیِ تعبیه‌شده در خود صفحه است. فایل‌های خام گزارش مشتریان و کالاها در بسته نیستند. فایل‌هایی که کاربر بعداً در صفحهٔ تحلیل انتخاب می‌کند، فقط با File API در حافظهٔ همان مرورگر خوانده می‌شوند و برای سرور ارسال یا در آن ذخیره نمی‌شوند.

مخزن و GitHub Pages عمومی‌اند؛ هر بازدیدکننده‌ای که نشانی را داشته باشد می‌تواند محتوا را ببیند. QR و لینک فقط نشانی‌اند و احراز هویت نیستند. این انتشار برای داده‌های تعبیه‌شدهٔ همین نسخه است؛ گزارش خام مشتریان، اطلاعات هویتی، رمزها و کلیدهای دسترسی نباید به مخزن اضافه شوند.

فونت Estedad با متن مجوز SIL Open Font License در `assets/fonts/OFL.txt` ارائه شده است. SheetJS CE در `assets/vendor/` تحت Apache-2.0 و QR generator تحت MIT است؛ متن مجوزهای هر دو همراه فایل است.
